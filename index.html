Two complete website proposals

This is an unofficial static prototype of the public ibjjf.com page set, rebuilt twice so a single design system is used on every page. Both versions include the home page, every destination in the main menu, and a few second-level examples (one championship, one results record, and one news article). Choose a version to browse, or jump from any page to the other version with the bar at the top.

Not the live IBJJF website. For design review only. No indexing.

Version A

2027 preview system

The system used on the interactive Rule Changes 2027 pages and the Uniform 2027 preview: Open Sans for body text, Roboto Condensed for titles, a darkest-navy header with a gold bar, gold left-border headings, soft cards, gold-underline tabs, and solid or gold buttons.

Version B

Normalized ibjjf.com system

The language already used most often on ibjjf.com, made consistent: the blue header and centered title band, outline buttons, a single gold (#faab19), one heading scale, one card radius, one table style, and the same ranking and guide components on every page.
